# 围棋AI教练 (Go-Coach)

一个专为围棋新手设计的AI教练系统，提供智能下棋指导和学习辅助。

## 🎯 项目特色

- **智能提示**：AI分析当前局面，推荐最佳落子位置
- **实时指导**：指出不当落子，提供改进建议
- **循序渐进**：从基础规则到高级策略的学习路径
- **简单易用**：Web界面，无需安装额外软件

## 🛠️ 技术栈

- **后端**：Python + Flask
- **前端**：HTML5 + CSS3 + JavaScript
- **AI算法**：基于规则的专家系统
- **部署**：本地运行，轻量级

## 🚀 快速开始

### 环境要求
- Python 3.7+
- 现代浏览器

### 安装运行
```bash
# 克隆项目
git clone https://github.com/li-hongxu/go-coach.git
cd go-coach

# 安装依赖
pip install -r requirements.txt

# 启动应用
python app.py
```

访问 `http://localhost:5000` 开始你的围棋学习之旅！
